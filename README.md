# AI-Assisted Coding — Learning Repository

This repository is a personal learning space for practising AI-assisted coding workflows. Use it to collect notes, examples, prompts, and small projects as you learn.

## Purpose
- Capture step-by-step progress while learning to code with AI assistance.
- Store best practices, prompt templates, and configuration that improves Copilot and other tools' responses.

## Included files
- [AI-BEST-PRACTICES.md](AI-BEST-PRACTICES.md) — step-by-step best practices for building with AI tools.
- [.github/copilot-instructions.md](.github/copilot-instructions.md) — repo-level instructions for Copilot.
 - [SLASH_AND_PARTICIPANTS.md](SLASH_AND_PARTICIPANTS.md) — guide and examples for slash commands and conversation participants.
 - `examples/` — practical examples including slash command usage.
 - [CODERABBIT.md](CODERABBIT.md) — guide: creating an account, using the CLI in VS Code, GitHub integration, and workflows for copying suggestions into this repo.
 - [LLM_TOOLS.md](LLM_TOOLS.md) — quick guides for Claude, Gemini, and OpenClaw CLIs, plus safe workflows.

## How to use
1. Keep entries small and focused: one idea, one example, one commit.
2. Update this README with progress notes or link to folders for each learning topic.
3. Add a short test or runnable example whenever you learn a new concept.
